## 🤝 Projetos em Grupo / Bootcamp

### 🚀 Bootcamp Avanti — Projeto em Equipe (MiAuDota)

Projeto desenvolvido de forma colaborativa durante o **Bootcamp Avanti**, uma aplicação moderna e intuitiva para facilitar a adoção de pets, conectando abrigos a adotantes de forma eficiente e segura.
Foco em aplicação prática de desenvolvimento web, trabalho em equipe e uso do GitHub em um ambiente semelhante ao profissional.

**Minhas contribuições no projeto:**
- 🤝 Trabalho em equipe e colaboração
- 🌐 Desenvolvimento front-end e back-end
- 🎨 Estruturação de layout e estilos
- 🗂️ Organização de código
- 🔧 Implementação de funcionalidades

  ## 🚀 Tecnologias Utilizadas
- **[React](https://react.dev/) 19** - Biblioteca JavaScript para interfaces de usuário
- **[Vite](https://vitejs.dev/)** - Build tool e dev server ultrarrápido
- **[TailwindCSS](https://tailwindcss.com/)** - Framework CSS utility-first
- **[React Router DOM](https://reactrouter.com/)** - Roteamento declarativo
- **[Axios](https://axios-http.com/)** - Cliente HTTP baseado em Promises
- **[React Hook Form](https://react-hook-form.com/)** - Gerenciamento performático de formulários
- **[Zod](https://zod.dev/)** - Validação de schemas TypeScript-first
- **[EmailJS](https://www.emailjs.com/)** - Envio de emails direto do cliente


- **[Node.js](https://nodejs.org/)** - Runtime JavaScript
- **[Express](https://expressjs.com/)** - Framework web
- **[Prisma ORM](https://www.prisma.io/)** - ORM para PostgreSQL
- **[PostgreSQL](https://www.postgresql.org/)** - Banco de dados relacional
- **[JWT](https://jwt.io/)** - Autenticação
- **[bcrypt](https://github.com/kelektiv/node.bcrypt.js)** - Hash de senhas
- **[Multer](https://github.com/expressjs/multer)** - Upload de arquivos
- **[Joi](https://joi.dev/)** - Validação de dados
- **[Nodemon](https://nodemon.io/)** - Auto-reload em desenvolvimento
- **[dotenv](https://github.com/motdotla/dotenv)** - Variáveis de ambiente
